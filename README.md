# Data Analytics_Portfolio_Projects_SQL

### 🎓 Advanced EdTech Analytics | PostgreSQL

An end-to-end SQL analytics project built using PostgreSQL to explore and analyse the EdTech business lifecycle — from lead acquisition and student enrollment to learning engagement, payments, course performance, and placements. Features relational database design, 18 interconnected datasets, advanced SQL queries, data quality checks, and an analytical reporting layer to generate actionable business insights.
